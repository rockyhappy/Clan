# 🚀 Splash & Onboarding Flow

This document details the implementation of the 3-page sliding onboarding splash screen.

---

## 📱 User Experience
1. **Slide 1**: *Clash Helper & Tracker* — Village upgrades & builder overview (Town Hall Canvas vector).
2. **Slide 2**: *Resource & Lab Analytics* — Loot & laboratory timers (Elixir & Dark Elixir Flask Canvas vector).
3. **Slide 3**: *War Planning & Clan Sync* — Clan War League coordination (War Shield Canvas vector).
4. **Top Controls**:
   - **☀️/🌙 Theme Switcher**: Toggle between Day Village and Night Base live.
   - **Skip**: Immediately navigates to `MainActivity`.
5. **Bottom Controls**:
   - Animated expanding dot indicators.
   - **Next / Get Started** button (`ClanButton`).
